# AI Resume Matcher 📄🤖

A full-stack AI web application that analyzes and matches student resumes against internship descriptions using Natural Language Processing (NLP).

## ✨ Features
- **Resume Parsing:** Extracts key skills, education, and experience from uploaded PDF/DOCX resumes.
- **NLP Similarity Scoring:** Calculates a match percentage between the candidate's resume and the target internship job description.
- **Keyword & Skill Gap Analysis:** Highlights matching keywords and identifies missing skills to help students tailor their applications.
- **Interactive Web Interface:** Simple, user-friendly dashboard for uploading resumes and pasting job descriptions.

## 🚀 Getting Started

### Prerequisites
Make sure you have Python 3.8+ installed on your machine.

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd ai-resume-matcher
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python app.py
   ```
   *(Or `streamlit run app.py` if built with Streamlit)*
